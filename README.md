# AetherMind AI — Enterprise AI Company Webpage

A modern, responsive web application built exclusively with **semantic HTML5** and **modern CSS3** (zero JavaScript dependencies).

## Included Files
- `index.html` — Complete webpage markup covering Hero, AI Products, Core Features, Industry Applications, Technology Stack & Benchmarks, Leadership Team, Contact Form, and Footer.
- `styles.css` — Responsive CSS Grid/Flexbox design system with glassmorphism, custom CSS variables, animated neural-core visualization, CSS-only mobile navigation drawer, and interactive form target feedback.

## How to Run
1. Extract `aethermind-ai-website.zip`.
2. Open `index.html` directly in any modern web browser (Chrome, Edge, Firefox, Safari).
